# Datos-Aerodinamicos-ClarkY

Repositorio de datos numéricos, matrices de cálculo y análisis de capa límite para el perfil aerodinámico Clark Y.

## Archivos del Repositorio

### Hojas de Cálculo (Excel)
1. **`CL VS AOA_PROCESADO.xlsx`**: Evaluación numérica del coeficiente de sustentación (C_L) frente al ángulo de ataque (alpha).
2. **`CD VS AOA_PROCESADO.xlsx`**: Evaluación numérica del coeficiente de resistencia (C_D), polares aerodinámicas y componentes de arrastre.
3. **`Analisis_optimizacion_trip.xlsx`**: Estudio paramétrico de sensibilidad, optimización de posición del disparador de transición (*trip*) y análisis estadístico.

### Datos de Capa Límite (Texto Plano - XFLR5)
4. **`BL DATA, Re66k.txt`**: Datos de capa límite para el caso base en flujo libre/limpio (Re = 66,064).
5. **`BL DATA, Re66k,trip10%.txt`**: Datos de capa límite con *trip* de transición al 10% de la cuerda (x/c = 0.10).
6. **`BL DATA, Re66k,trip30%.txt`**: Datos de capa límite con *trip* de transición al 30% de la cuerda (x/c = 0.30).
7. **`BL DATA, Re66k,trip50%.txt`**: Datos de capa límite con *trip* de transición al 50% de la cuerda (x/c = 0.50).
